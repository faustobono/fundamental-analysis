# Instrucciones para Claude Code

Este repositorio usa `AGENTS.md` como fuente única de instrucciones compartidas.

Antes de cualquier cambio, leé en este orden:

1. `AGENTS.md`
2. `kickoff.md`
3. `README.md`
4. `DECISIONS.md`
5. `TODO.md`

Cumplí todas las reglas de `AGENTS.md`, especialmente la preservación de cambios
existentes, la ejecución de tests sin red y la prohibición de guardar secretos.
